# ChangingUnits

**Live site: [www.changingunits.com](https://www.changingunits.com)**

A free unit converter covering 1,600+ conversion pages across 14 categories. It is built as a fully static site, generated by a small Node.js build system from a single data file, and deployed automatically to Cloudflare Pages.

I built it end to end: product scoping, information architecture, front-end, build tooling, SEO, analytics and deployment.

---

## What it does

- Instant conversion as you type, with a swap button, copy-to-clipboard and shareable URLs (`?v=`)
- A quick-reference table, the conversion formula and a short explanation on every page
- A searchable From/To unit picker on each category hub
- A glossary with a definition page for every unit
- Works on mobile and desktop

**Categories (14):** Length, Weight, Temperature, Area, Volume, Speed, Time, Data, Energy, Pressure, Fuel Economy, Angles, Frequency, Fun Units (smoots, bananas, football fields and similar).

## How it's built

There is no framework and no runtime backend. Every page is plain HTML, CSS and JavaScript, pre-rendered at build time.

```
changingunits.com/
├── _build/
│   ├── data.js        # Single source of truth: categories, units, converters
│   ├── templates.js   # HTML templates (converter, category hub, glossary)
│   └── build.js       # Generates every page + sitemap.xml
├── length/ weight/ ... # Generated category hubs and converter pages
├── glossary/          # Generated unit definition pages
├── index.html         # Homepage
├── about/ contact/ privacy-policy/ disclaimer/
├── robots.txt
└── sitemap.xml        # Auto-generated on each build
```

**Workflow**

```bash
cd _build
node build.js                      # build everything
node build.js length               # rebuild one category
node build.js length cm-to-inches  # rebuild one page
```

Adding a new converter or category means editing `data.js` and re-running the build. Pushing to `main` triggers an automatic deploy on Cloudflare Pages.

## Technical highlights

- **Data-driven generation:** one data file produces category hubs, converter pages, glossary pages and the sitemap. Full-coverage checks confirm every unit pair in each picker has a working page.
- **Correct conversions:** factor-based conversions share a common base unit per category. Temperature uses dedicated formulas, and inverse fuel-economy units (L/100km) are handled separately.
- **SEO fundamentals:** unique titles and meta descriptions, canonical URLs, JSON-LD (`WebApplication` and `BreadcrumbList`), an auto-generated sitemap with `lastmod`, and `robots.txt`. Validated with Google's Rich Results Test and Search Console.
- **Internal linking:** each converter page surfaces related conversions ranked by shared units, and links to the glossary entries for both units.
- **Performance and accessibility:** non-blocking font loading, static pages served from Cloudflare's CDN, and contrast and link-styling fixes driven by Lighthouse and PageSpeed Insights audits.
- **Analytics:** Google Analytics 4 on every page.
- **Build validation:** generated pages are syntax-checked after each build, which caught several template-escaping bugs early.

---

## Decisions and trade-offs

- **Static over dynamic:** the content doesn't change per user, so pre-rendering gives speed, low cost and simple hosting.
- **Dropped currency conversion:** I prototyped live exchange rates but removed the feature. The free APIs I evaluated had limited currency coverage or request limits that didn't suit a high-traffic public site, and I didn't want to ship unreliable rates.
- **Scoped unit lists:** obscure units are limited to the fun-units category rather than being paired with every other unit, which keeps the pickers clean and avoids low-value pages.
